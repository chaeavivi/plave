# PLAVE 응원법 타자 연습 ⌨️💙💜💗❤️💚

플레이브 응원법을 **가사 한 줄씩** 따라 치는 타자 연습 페이지입니다.
서버·설치 없이 `index.html` 하나로 돕니다. (`lyrics.js` = 가사, `app.js` = 동작)

## 열기
- `typing/index.html` 더블클릭 → 바로 실행
- GitHub Pages: 저장소 **Settings → Pages** 에서 브랜치 지정 후 `https://<아이디>.github.io/<저장소>/typing/`

## 화면 규칙 (워드 문서 규칙 그대로)
| 문서 표기 | 화면 |
| --- | --- |
| `[예준]` 등 멤버 태그 | `│ • 예준 PART` 배지 + 맞게 치면 **멤버 색**, 틀리면 **흰색** (타이핑엔 포함 안 됨) |
| `[PLAVE]` | 멤버 전원 파트. 5색 배지, 맞게 치면 글자가 5색으로 |
| `[플리]` | 플리 파트 태그 (뒤에 오는 `<…>` 줄은 흰색 플리 PART) |
| `**볼드**` | 🤍 점선 박스 = 플리가 멤버와 **같이 부르는 파트**, 배지에 `🤍 플리 함께` 표시 |
| `<응원법>` 한 줄 전체 | `│ • 플리 PART` 흰색 배지, 글자 흰색 (`<>` 기호는 안 보임) |
| `<가>` 가사 사이 응원법 | 🤍가 처럼 흰색 하트 + 흰색 글자 |
| `<함성>` `<환호>` | 아무거나 입력하고 ENTER 하면 통과 |
| `[00:10]` `[3:25 플리]` | ⏱ 시간 배지로만 표시 (타이핑 X) |
| 줄바꿈 | 문서에서 엔터 친 곳에서 그대로 끊어서 연습 |

- **응원법 포함 ON/OFF**: OFF 면 `<>` 응원법이 빠지고 가사만 연습합니다.
- **ENTER** = 다음 줄 (정확히 입력해야 넘어감), **SKIP** = 건너뛰기
- 완주하면 **타수(타/분) · 정확도 · 시간**이 기록되고, 정확도 95% 이상이면 **PLLI 합격증** PNG 를 저장할 수 있어요.
  기록은 브라우저(localStorage)에 곡별 Top 5 로 저장됩니다.
- 타수는 한글 자모 입력 수 기준입니다. (예: "닿" = ㄷ+ㅏ+ㅎ = 3타, "왜" = ㅇ+ㅗ+ㅐ = 3타)

## 수정 후 반영이 안 보일 때
`index.html` 의 `app.js?v=...` / `lyrics.js?v=...` 값을 올려 주세요(예: 날짜). 브라우저 캐시를 건너뛰고 새 파일을 받습니다.

## 곡 추가하기
트랙 순서는 `lyrics.js` 배열 순서 그대로입니다. 06~10번(Pump Up The Volume!, Dash, 숨바꼭질, BBUU!, Born Savage)은
`locked: true` 로 들어 있어 "준비중"으로 보입니다. 가사 문서가 준비되면 `locked: true` 줄을 지우고
워드 문서에 적던 그대로 `text` 에 붙여넣으면 바로 열립니다.

```js
{
  id: "new-song",          // 영문 아이디 (기록 저장 키)
  title: "곡 제목",
  accent: "#5DA9FF",       // 트랙 칩 색
  text: `
[예준] 첫 줄 가사
**같이 부르는 부분**
<응원법>
<함성>
`,
},
```
